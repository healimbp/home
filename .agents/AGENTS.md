# Workspace Rules for HealimBP (해아림한의원 인천부평점)

## 📌 주요 행동 지침 및 상시 적용 규칙

### 0. 🚫 글 작성 매너리즘 및 중복 방지 상시 원칙 (Anti-Repetition & Multi-Dimensional Diversity)
모든 칼럼, 블로그, 티스토리, Q&A 원고 작성 시 시간이 지나도 글이 정형화되거나 비슷해지지 않도록 다음 **5대 다변화 축**을 상시 강제 적용합니다:
1. **🚫 약선차/한방차 내용 일체 기재 금지**: 산조인차, 대추차, 결명자차 등 차(Tea) 관련 내용은 전면 배제하고, 물리적/행동학적 생활 관리 루틴(이완 호흡, 족욕, 수면 환경, 햇볕 쬐기, 근막 스트레칭)으로 구성. (⚠️ 주의: 본문 제목이나 소제목, 썸네일에 '약선차 제외'라는 메타 문구를 직접 노출하지 말고, 자연스럽게 물리적/행동학적 루틴만 작성할 것)
2. **진부한 상투적 도입부 전면 금지**: "최근 현대인들에게 흔히 발생하는...", "바쁜 현대 사회에서..." 등 클리셰 일체 금지 -> 출근길 만원 지하철, 수험생 시험 직전 복통, 야간 교대근무 얕은 잠 등 구체적 생애주기·직군별 **생생한 임상 상황**으로 시작.
3. **비유(Metaphor)의 다채로운 변주**: 편도체/자율신경 기전 설명 시 브레이크 마모, 스마트폰 백그라운드 앱 100개 과각성, 자동차 엔진 냉각수 고갈(상열하한), 방음벽 없는 방 등 글마다 차별화된 일상 비유 사용.
4. **심층 한방 방제학 & 경혈학 차별화**: 단순 4단계 나열 탈피 -> 증상/체질별 구체적 한약 처방(사역산, 귀비탕, 천왕보심단, 반하후박탕, 온담탕, 억간산, 영계출감탕 등) 및 핵심 혈자리(백회, 신문, 단중, 태충, 풍지 등)의 작용 원리를 글마다 깊이 있게 다변화.
5. **5대 본문 전개 포맷 로테이션 (공장형 템플릿 복붙 절대 금지)**: ① 기전 심층 탐구형, ② 오해와 진실 팩트체크형(O/X 박스), ③ 감별 진단/비교 분석형(비교 테이블), ④ 단계별 회복 로드맵형(타임라인), ⑤ 임상 사례 중심 심층 고찰형(진료 노트)을 균등하게 순환하여 글마다 구조와 레이아웃을 완전히 차별화.
6. **생활 속 힐링 팁의 초구체화**: "충분한 휴식" 배제 -> 4-7-8 이완 호흡, 90분 수면주기, 기상 직후 15분 햇볕 쬐기, 취침 90분 전 족욕, 블루라이트 차단 등 손에 잡히는 구체적 루틴 제시. (원고 본문이나 소제목에 '약선차 제외' 문구를 직접 표기하지 않고 자연스럽게 행동/물리 요법만 작성)

### 1. 블로그 작성 요청 시 (One-Stop All-in-One Protocol)
사용자가 **"[질환/지역] 블로그 써줘/만들어줘"**라고 요청하면, 묻거나 확인하지 않고 즉시 다음을 원스톱으로 일괄 실행합니다:
1. **고화질 5종 카드뉴스/썸네일 이미지 자동 생성 (1080x1080)**:
   - `01_naver_main_thumbnail.jpg`
   - `02_point1_cause.jpg`
   - `03_point2_checklist.jpg`
   - `04_point3_treatment.jpg`
   - `05_point4_selfcare.jpg` (약선차 내용 제외)
   - 저장 경로: `static/blog-images/` 및 `static/blog-images/[주제명]/`
2. **정립된 4단 구조 블로그 완성형 원고 생성**:
   - 3대 패턴 제목 옵션 (1개 추천 + 2개 대안)
   - 환자 생생 독백 인트로 (다양한 페르소나 적용)
   - POINT 01 (원인 분석 기전 - 다채로운 비유)
   - POINT 02 (자가진단 체크리스트)
   - POINT 03 (1:1 맞춤 한방 치료 솔루션 - 심층 방제/경혈)
   - POINT 04 (생활 속 힐링 실천 팁 3가지 - 초구체적 행동/환경 루틴, 약선차 배제)
   - ❓ **진료실 자주 묻는 질문 (FAQ 3~4선 - 칼럼급 다변화 필수)**: 획일적인 3대 질문(양약 병행, 치료 기간, 첫 검사) 기계적 반복 절대 금지 -> 홈페이지 칼럼과 동일하게 질환별 특화 질문(음주/카페인/식습관, 손발 열감/체온, 생체시계/낮잠/교대근무, 행동요법, 호전 순서 등) 5대 테마 중 3~4개를 골고루 선별하여 실전 진료실 상담 수준으로 생생하고 다채롭게 작성
   - 이미지 삽입 위치 가이드 마커
   - 권형근 대표원장 위로 메시지 & 부평점 진료 안내
   - 네이버 검색 상위노출 해시태그 8~10개
   - 📋 **원클릭 복사용 단일 텍스트 블록(Code Block) 제공**: 제목 옵션부터 해시태그까지 원고 전체를 하나의 코드 블록(` ```text `) 안에 온전하게 담아 출력하여 원클릭 'Copy'로 네이버 스마트에디터에 바로 붙여넣을 수 있도록 제공.
   - ⚠️ **[중요 서식 규칙] 마크다운 볼드 표시(`**`) 절대 사용 금지**: 블로그 에디터 복사-붙여넣기 시 `**` 기호가 그대로 노출되어 일일이 지워야 하므로, 원고 본문 및 강조 문구에 `**` 기호를 쓰지 않고 따옴표(' ', " "), 대괄호([ ]), 글머리 기호(•, ✓), 자연스러운 문장으로 작성합니다.
3. **클릭 가능한 이미지 파일 링크(`file:///...`) 및 폴더 링크 제공**

### 2. 다채널(블로그 5개 / 티스토리 / 홈페이지 / 지식iN / 플레이스) 전략적 운영 원칙
1. **네이버 블로그 5개 (유사문서 방지 & 증상별 분점)**:
   - 계정 간 키워드 자가잠식 방지를 위해 주제/질환군 분리 (정신건강 / 수면·자율신경 / 소아청소년 틱·ADHD / 신체·담적 / 원장 브랜딩)
   - 네이버 스마트블록(의도형/상황형 롱테일 키워드) 맞춤형 타깃팅
2. **티스토리 (구글 SEO & 롱폼 의학 칼럼)**:
   - E-E-A-T 기반 심층 기전 분석, H2/H3 계층 구조, 인천부평점 단독 홈페이지 백링크 자연스러운 유도
   - **질환 특화 FAQ 섹션 필수 포함**: 획일적 질문 복붙 금지, 환자 실전 고민 기반 5대 테마 순환 적용으로 질문 중복 방지 및 E-E-A-T 신뢰도 강화
   - 🖼️ **대표 썸네일 HTML 파일 내장 원칙**: 텔레그램 발송 시 썸네일을 별도 사진(`sendPhoto`)으로 분리 발송하여 채팅창을 어지럽히지 않고, 첨부되는 티스토리 HTML 파일 상단에 완결된 `<img>` 태그로 내장하여 한 번에 전달.
3. **단독 홈페이지 (전환 허브 Hub & 포털 웹문서 1페이지)**:
   - SEO 메타태그 및 Schema.org (MedicalClinic, FAQPage) 유지
   - 방문 환자가 '자가진단 → 전화/카카오톡/네이버예약'으로 전환되는 3대 CTA 상시 연계
4. **네이버 지식iN (고관여 환자 1:1 맞춤 상담)**:
   - 생생한 환자 고민 공감 + 권형근 원장의 4단 전문 의학 답변 + 네임카드 브랜딩
5. **네이버 플레이스 연계**:
   - 모든 채널 콘텐츠 하단에 부평역 7번 출구 위치, 야간진료(월·수·금 20시), 네이버 예약/전화 바로가기 정보 완비

### 3. 홈페이지 및 티스토리 칼럼 작성 시
- **5대 본문 전개 포맷 로테이션 적용**: 단일 템플릿 복붙을 엄격히 금지하고 기전형, 팩트체크형, 감별비교형, 회복로드맵형, 임상에세이형 중 적합한 포맷을 선택하여 전용 UI 컴포넌트(비교표, 타임라인, O/X 카드, 진료노트 등)와 함께 다채롭게 작성.
- 3대 제목 작성 패턴(맨 앞 지역명 / 중간 지역명 삽입 / 순수 질환형) 1:1:1 균등 순환
- **FAQ 다변화 필수 (홈페이지 & 티스토리 공통)**: 획일적인 3대 질문(양약 병행, 치료 기간, 첫 검사) 기계적 반복 절대 금지 -> 질환별 특화 질문 2개 이상 + 5대 테마(증상 대처, 원인 검사, 약물 감량, 호전 순서, 일상·가족 대처) 순환 적용

### 4. Q&A 상담사례 작성 시 (healim.com/5-9 온라인 문의 기반)
- 해아림 공식 온라인 문의(healim.com/5-9) 기반: 생생한 환자 고민(Q) + 권형근 대표원장의 1:1 심층 상담 칼럼형 답변(A)
- **첫 인사말 고정**: 반드시 `안녕하세요. 해아림한의원 인천부평점 원장 권형근입니다.`로 시작 (지식iN, 닥톡 등 외부 플랫폼 호칭 절대 사용 금지)
- 인위적 소제목/체크박스 배제, 공감-기전해설-맞춤치료-생활관리-맺음말의 유려한 상담 에세이 형식
