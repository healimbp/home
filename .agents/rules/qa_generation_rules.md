# Q&A 상담 사례 작성 규칙 (네이버 지식iN 기반)

## 📌 목적 및 작성 원칙
네이버 지식iN(의료/한의학/신경정신과)의 실제 환자 고민을 바탕으로, **환자 관점의 생생한 질문(Q)**과 **권형근 대표원장(한방침구과 전문의)의 1:1 심층 전문 답변(A)**을 작성하여 신뢰도와 SEO 롱테일 유입을 극대화합니다.


## 3. 네이버 지식iN 스타일 환자 질문(Q) 구성 가이드
- **구체적인 상황 묘사**: 출퇴근길 지하철, 시험 기간, 직장 회의, 잠자리, 육아 스트레스 등 구체적 배경 제시
- **병원 검사 경험 언급**: "이비인후과/응급실/내과 검사는 정상인데...", "수면제/정신과 약을 먹고 있는데..." 등 실제 환자들의 답답함 반영
- **핵심 질문 포인트**:
  1. 원인이 무엇인지? (스트레스 vs 신경계 이상)
  2. 병원 약을 줄이거나 끊고 한방 치료로 가능한지?
  3. 한의원에서는 어떤 검사와 치료를 하는지?

---

## 4. 권형근 대표원장 전문 답변(A) 구성 표준 4단 구조

### ## 1. [질환의 신경학적/한의학적 발생 기전]
- 환자가 알기 쉽게 뇌 신경계(편도체, 기저핵, 전두엽, 자율신경)와 한의학적 병리(간기울결, 수승화강 불균형, 심화 등)를 접목하여 명쾌하게 해설.

### ## 2. [자가진단 체크리스트 또는 감별 진단 기준]
- 환자가 스스로 상태를 점검할 수 있는 4~6개 문항의 체크리스트 또는 오인하기 쉬운 질환과의 감별법 제시.

### ## 3. [가정 내 생활 관리 및 응급 대처법]
- 호흡법, 이완 요법, 수면 환경, 식습관 등 실천 가능한 2~3가지 꿀팁.

### ## 4. [해아림한의원 인천부평점의 1:1 맞춤 치료 솔루션]
- 3대 정밀 검사(뇌파, 자율신경, 체열, 심리평가)
- 맞춤 한약(안신, 청열, 기혈보강) + 약침 + 추나요법 + NeuronFlex 두뇌 훈련
- `<div class="qa-highlight-card">` 내에 권형근 대표원장의 따뜻한 위로와 격려 조언 필수 포함.
